HƯỚNG DẪN CHƠI

3. Bấm "Đặt Cược". Nếu chọn trúng bom, mất tiền. Nếu chọn ô an toàn, nhận tiền theo hệ số.
4. Nạp/Rút chờ Admin duyệt.
